# README für die Postervorbereitung

### Themenauswahl
Jeder bitte jeweils ein Thema aussuchen, zu dem ein Postersatz erstellt und am 10.10. betreut wird. Die Wahl bitte in Zulip bekanntgeben, um Arbeitsdopplung zu vermeiden. 

### Postervorbereitung
Den Ordner "my poster" kopieren und in eurem Ordner ablegen. Wichtig sind nur die Dateien myposter-front.tex und myposter-back.tex. Alle weiteren .tex-Dateien (Preamble_xyz.tex) sind Dependency-Dateien, die die Posterdatei als Input verwendet; ihr müsst damit nichts machen. Library.bib ist eine standard BibTeX-Datei, falls ihr das Quellenverzeichnis verwenden wollt.
